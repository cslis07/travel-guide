🏠 메인 페이지 (/)

상단 헤더에 환율 바, 환율 계산기, 히어로 검색 위젯(항공·숙소·국내), 인천공항 실시간 배너, 퀵북, 인기 여행지 카드 순으로 구성됩니다.

  • 💱
    환율 바USD/JPY/EUR/VND/THB → KRW 실시간 환율 (24시간 단위 갱신)
  • 🧮
    환율 계산기금액 입력 → 6개 통화 즉시 변환. 키 입력에 따라 실시간 갱신
  • 🔍
    검색 위젯항공권 / 호텔 / 국내여행 3개 탭. 외부 OTA로 검색 위임
  • ✈
    인천공항 배너실시간 정보 페이지(/airport)로 바로 이동
  • 🗺
    목적지 카드9개 여행지(오사카·후쿠오카·도쿄·교토·방콕·다낭·발리·제주·부산·강릉)
✈ 인천공항 페이지 (/airport)

입력예시결과

잔여 시간표시 색상안내 메시지
출발 60분+ 이전기본"X시간 X분 후 게이트 도착 권장"
출발 60분~30분⚠ 주황"X분 후 게이트로 이동 권장"
출발 30분 이내🚨 빨강"지금 게이트로 이동하세요"

🔔 게이트 변경 알림

60초마다 백그라운드 자동 갱신. 게이트·시간·운항 상태가 바뀌면 토스트 + OS 푸시 알림 표시.

💡 🔔 알림 켜기 버튼으로 OS 알림 권한 활성화. 사이트가 백그라운드여도 알림 수신.

✅ 체크리스트 + 진행 트래커

출국 6단계 진행 트래커 + 34개 준비물 체크리스트.

단계평균 소요주요 활동
1. 체크인·수하물5~20분카운터 발권 + 짐 위탁
2. 보안검색10~25분액체·노트북·신발 분리
3. 출국심사5~20분자동심사 등록 시 빠름
4. 면세점·라운지자유탑승 30분 전까지 여유
5. 게이트 이동5~15분탑승동(P03)은 +5분
6. 탑승 완료30분 전최종 탑승 완료

체크리스트는 6개 그룹(필수서류·결제·전자기기·의류세면·위생약품·기타)으로 정리되어 있고, 항목 클릭 시 체크됩니다. 진행률은 상단 게이지로 표시.

🔍 통합 검색 단축키

인천공항 페이지에서 Ctrl + K (또는 우상단 🔍 버튼) → 8개 탭, 7개 액션, 항공편, 시설을 한 화면에서 즉시 검색.

  • ⬆️⬇️
    방향키로 선택 이동결과 목록에서 위/아래로 이동
  • ↩️
    Enter로 즉시 이동선택한 항목으로 점프
  • ⎋
    ESC로 닫기검색 모달 닫고 이전 화면으로
🔗 공유 + URL 딥링크

우상단 🔗 버튼 → 현재 페이지 URL 복사 (모바일은 시스템 공유 시트). 인천공항 페이지의 특정 탭으로 직접 진입하려면 URL 해시 사용.

URL결과
/airport#tab=fav내 편명 탭으로 바로
/airport#tab=prep&sub=lounge출국 준비 → 라운지로
/airport#tab=prep&sub=check출국 준비 → 체크리스트로
🌙 테마 + 🌐 한/영

우상단 토글로 다크/라이트 모드 전환. 시스템 prefers-color-scheme 자동 감지. EN 버튼으로 영어 번역 (탭·서브탭).

📱 홈 화면에 추가 (PWA)

모바일 브라우저에서 "홈 화면에 추가" → 앱처럼 작동. Service Worker가 정적 자산을 캐싱해 오프라인에서도 마지막 화면이 표시됩니다. 실시간 API는 항상 네트워크 우선.

✅ Chrome (Android): 주소창 옆 ⋮ → "홈 화면에 추가"
✅ Safari (iOS): 공유 → "홈 화면에 추가"
✅ PC Chrome: 주소창 우측 설치 아이콘
